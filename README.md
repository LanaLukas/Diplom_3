# Diplom_3

UI-тесты для сервиса Stellar Burgers (Selenium + pytest).

Установить зависимости - `pip install -r requirements.txt`

Запуск тестов - `pytest -v`

Сгенерировать allure отчёт - `pytest -v --alluredir=allure_results`

Открыть отчёт - `allure serve allure_results`
___

Проверяемые сценарии:

- Конструктор:
  - Переход по клику на «Конструктор»
  - Переход по клику на «Лента заказов»
  - Клик на ингредиент открывает модальное окно с деталями
  - Закрытие модального окна кликом по крестику
  - Добавление ингредиента увеличивает каунтер
  - Залогиненный пользователь может оформить заказ

- Лента заказов:
  - Клик на заказ открывает детали заказа
  - Заказы пользователя отображаются в ленте заказов
  - Счётчик «Выполнено за всё время» увеличивается при новом заказе
  - Счётчик «Выполнено за сегодня» увеличивается при новом заказе
  - Номер нового заказа появляется в разделе «В работе»

- Личный кабинет:
  - Переход по клику на «Личный кабинет»
  - Переход в раздел «История заказов»
  - Выход из аккаунта

- Восстановление пароля:
  - Переход на страницу восстановления пароля
  - Ввод почты и клик по кнопке «Восстановить»
  - Клик по кнопке показать/скрыть пароль делает поле активным
